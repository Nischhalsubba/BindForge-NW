# Support policy

## Product support

Use GitHub issues for reproducible product defects, accessibility problems, broken layouts, incorrect generated output, and catalog corrections.

Include the browser, device or viewport, affected preset or command, reproduction steps, screenshots, and whether saved browser data was present.

## Not supported

BindForge NW cannot:

- read or modify a player's Neverwinter keymap
- apply commands inside the game
- recover game accounts or credentials
- guarantee undocumented commands after a game patch
- provide official Cryptic Studios, Arc Games, Gearbox, or Neverwinter support

## Response expectations

Issues are reviewed according to severity and available maintainer time. Security reports must follow `SECURITY.md` and should not be filed publicly with exploitable details.

## Data and privacy

Preferences, favourites, collections, and edited keys are stored in the user's browser unless exported or shared. Support reports should not contain credentials, tokens, private messages, or unrelated personal information.
